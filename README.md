# SleepMaxxer

A Simple Red Light Filter to help with melatonin production, Similar to Apple's accessibility feature.

## Build

```powershell
.\build.ps1
```

The executable is created at:

```text
bin\SleepMaxxer.exe
```

## Usage

- Toggle the red filter on or off.
- Adjust filter intensity from 0% to 100%.
- Optionally minimize the app to the system tray when closing.
