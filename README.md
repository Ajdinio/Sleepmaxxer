# SleepMaxxer for Windows

A Simple Red Light Filter to help with melatonin production, Similar to Apple's accessibility feature.
Windows only.

## Installation

Clone this repository:

```powershell
git clone https://github.com/Ajdinio/Sleepmaxxer.git
cd Sleepmaxxer
```

Then build the app:

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

The executable is created at:

```text
bin\SleepMaxxer.exe
```

## Usage

- Toggle the red filter on or off.
- Adjust filter intensity from 0% to 100%.
- Optionally minimize the app to the system tray when closing.
- Full Red Mode to use as a Nightlamp. Press ESC to close
